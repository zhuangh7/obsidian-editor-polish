# 编辑界面美化 (Editor Polish)

一个本地 Obsidian 插件，用来解决默认编辑界面的几个痛点：正文宽度不灵活、表格列宽不能拖、以及一些基础 UI 粗糙的问题。

## 功能

### 1. 可选正文宽度
- 预设：窄 650 / 中 800 / 宽 1000 / 超宽 1200 / 全屏。
- 自定义任意宽度：数字按 px 处理，也支持 `rem` / `ch` / `%`，或填 `full` 表示全屏。
- 底部状态栏有一个 `↔ 宽度` 按钮，点一下即可弹出菜单快速切换。
- 命令面板命令：循环切换宽度、`+60px`、`-60px`、设为全屏。
- 按笔记覆盖：在笔记属性(frontmatter)里写 `editor-width: 1000`（或 `full`），只改这一篇。
- 同时作用于「实时预览 / 源码」编辑视图和「阅读」视图。

### 2. 表格列宽可拖拽
- 把鼠标移到表头单元格的右边缘，出现竖线即可左右拖动调整列宽。
- 双击该边缘可重置整张表的列宽。
- 可选「记住列宽」：按 `笔记路径 + 表头 + 列数` 记忆。Markdown 本身不存列宽，属尽力保存；表头或列数变化后旧记录自然失效。
- 命令：重置当前笔记的表格列宽 / 清除所有已保存列宽。

### 3. 通用美化（均可在设置里单独开关）
- 表格：清晰边框、表头底色、斑马纹、悬停高亮、圆角、超宽自动横向滚动。
- 排版：更舒适的行距、标题间距、引用块竖线、行内代码底色、分割线。
- 滚动条：更纤细、圆润。

## 使用
设置 → 第三方插件 → 启用「编辑界面美化」。所有选项在其设置页中。

## 卸载 / 关闭
在设置里关闭或卸载即可，所有注入样式、表格内联宽度与包裹元素都会自动还原。
